<sub>01 / PROJECT OVERVIEW</sub>

## Making Metro Operations Easier to Manage

</div>

The **Metro Rail Management System** is a web-based application developed using ASP.NET MVC and C#. It is designed to support essential metro railway operations through a centralized management interface.

The application brings together user authentication, station and train management, ticket booking, distance-based fare calculation, seat availability tracking, and ticket cancellation with role-based access control.

The project demonstrates practical web application development, application logic, and the organization of transport management workflows.

<sub>04 / APPLICATION WORKFLOW</sub>

## How It Works

</div>

The application brings together several connected operational tasks:

1. **Authenticate:** Users access the application through the authentication workflow.
2. **Manage:** Station and train information is organized through management functions.
3. **Book:** Users follow the ticket booking workflow for a journey.
4. **Calculate:** The system calculates fares based on journey distance.
5. **Track:** Seat availability is monitored as part of booking.
6. **Cancel:** The ticket cancellation workflow handles cancellation requests.

Role-based access control supports appropriate access to application features.

<sub>05 / GETTING STARTED</sub>

## Run the Project Locally

</div>

### Prerequisites

- Windows or another environment compatible with the project's .NET version
- Visual Studio with the required .NET development components
- The .NET SDK or runtime required by the project
- Any database server and dependencies specified in the project configuration

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/momin078/MetroRailManagementSystem.git
```

**2. Open the project**

Navigate to the downloaded folder and open:

```text
MetroRailManagementSystem.sln
```

Open the solution using Visual Studio.

**3. Restore dependencies**

Allow Visual Studio to restore the NuGet packages required by the solution. If needed, use the NuGet Package Manager or the appropriate `dotnet restore` command for the project.

**4. Configure the application**

Check the project's configuration files and source code for:

- The required .NET version
- Database connection settings, if applicable
- Any required environment-specific configuration
- Initial database setup instructions

Configure these settings according to your local environment.

**5. Build and run**

Build the solution in Visual Studio, resolve any configuration issues, and run the application using the appropriate startup project and launch settings.

*Exact database setup and startup commands depend on the repository's actual configuration.*
